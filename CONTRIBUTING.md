# Contributing

Messer Lineup is a personal tool, published as it is. **Pull requests are not being accepted** —
because the project has one owner and its roadmap is their own use of it.

**Issues are for two things:** a takedown request for a listing, and a data correction for a wrong
venue, town or date. Feature ideas are read and parked unless I ask for them.

If you find a security problem, do not open an issue: see [`SECURITY.md`](./SECURITY.md).

Forking is welcome and the license allows it. If you build on this, take the parts that are
interesting and leave the rest.
