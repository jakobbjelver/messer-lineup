# Contributing

Messer Lineup is a personal tool, published as it is. **Pull requests are not being accepted**, and
issues are closed by default — not out of rudeness, but because the project has one owner and its
roadmap is their own use of it.

If you find a security problem, do not open an issue: see [`SECURITY.md`](./SECURITY.md).

Forking is welcome and the license allows it. If you build on this, take the parts that are
interesting and leave the rest.
